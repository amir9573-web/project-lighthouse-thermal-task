# Data provenance

All CSV records were created for this task from the declared two-body energy balances with a fixed random seed, Gaussian sensor noise, sensor affine calibration and acquisition masks. No external dataset or personal information is used. The measurements are synthetic and are not evidence of an actual experiment. Data files may be used, modified and redistributed within the Project Lighthouse assessment and its evaluation workflows. There are no third-party dataset licence restrictions to resolve.

The data-generation program is intentionally excluded from the task repository. True generating parameters and random seed are not supplied to the agent. Model equations and acquisition conventions are provided because they are part of the engineering measurement contract. Neither those conventions nor the protocol contains fitted answers or marking logic.
